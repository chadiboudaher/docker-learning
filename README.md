# Docker Learning

This repository documents my hands-on journey learning Docker and containerization.

I am using it to organize my notes, practice Docker commands, complete labs, and experiment with concepts such as networking, volumes, Docker Compose, Dockerfiles, image management, and application containerization.

- Containerizing and deploying applications
